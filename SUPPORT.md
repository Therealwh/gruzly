# Support

Found a bug or want a feature?

1. **Bug** — [open a bug report](https://github.com/Therealwh/gruzly/issues/new?template=bug_report.yml)
   with your Gruzly version, OS, and reproduction steps. Screenshots are welcome
   (both themes, please, if it's visual).
2. **Feature request** — [open a feature request](https://github.com/Therealwh/gruzly/issues/new?template=feature_request.yml).
   Describe the problem first, then the desired behavior.
3. **Question** — check the [README](README.md) troubleshooting notes first;
   if it's not covered, open a discussion or an issue labeled `question`.

Logs live in the app data directory (`gruzly.log`). **Never paste cookies,
tokens, or URLs you consider private.**

For security issues, see [SECURITY.md](SECURITY.md) — please use private
reports, not public issues.
