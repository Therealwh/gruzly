# Code of Conduct

## Our standard

Be a decent engineer: critique code, not people; assume good faith; keep
discussions on-topic; no harassment, trolling, or personal attacks.

## Scope

Applies to all project spaces — issues, pull requests, discussions, chat — and
when representing the project elsewhere.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code,
and may temporarily or permanently ban repeat offenders. Report problems to
the maintainers through a private GitHub contact request.

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
